# Project handoff

Read [the handoff contract](../../references/handoff-contract.md).

1. Confirm the goal, recipient context, and allowed data.
2. Capture current Git state, exact paths, runtime requirements, and external dependencies.
3. Include only needed source, assets, specifications, commands, and verification evidence.
4. Add a manifest and checksums for material artifacts.
5. Document known limitations and the next executable action.
6. Test the handoff from a clean location when practical.
