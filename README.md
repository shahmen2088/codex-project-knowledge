# Project Knowledge

Четыре навыка для превращения разрозненной истории работы в безопасную и переносимую проектную память.

## Навыки

| Навык | Результат |
|---|---|
| `history-audit` | приватный инвентарь проектов и повторяющихся тем без изменения истории |
| `decision-log` | решения, варианты, допущения и последствия в компактном журнале |
| `project-handoff` | пакет продолжения проекта без зависимости от исходного чата |
| `skill-repository-curation` | оценка skills по применимости, активации, поддержке, лицензии и пересечениям |

## Установка

```powershell
pwsh .\install.ps1 -Target codex
pwsh .\install.ps1 -Target opencode
```

## Проверка

```powershell
pwsh .\scripts\validate.ps1
```

Минимальный контракт передачи проекта находится в `references/handoff-contract.md`, тесты активации — в `tests/activation-cases.md`.

Репозиторий не содержит выгрузок чатов, локальных баз, корпоративных документов или персональных данных. Внешние источники перечислены в `THIRD_PARTY.md`.
